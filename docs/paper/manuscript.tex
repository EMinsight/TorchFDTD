\title{\Large\bfseries TorchFDTD: a Python-first CUDA finite-difference
time-domain workbench for photonics and independent design ensembles}
\author{Hyoseok Park}
\date{\small Technical manuscript draft\\21 September 2026}

\begin{document}
\maketitle

\begin{abstract}
TorchFDTD combines a serializable Python scene model, a browser-based geometry editor and a CUDA finite-difference time-domain solver. The implementation advances six electromagnetic field components on a Yee grid and supports convolutional perfectly matched layers, periodic and Bloch boundaries, passive Drude and Lorentz dispersion, and static graded rectilinear meshes. Time-domain point monitors and frequency-domain plane monitors share a consistent complex Fourier convention. Plane monitors account for Yee spatial staggering and the magnetic half time step before evaluating signed power-flux ratios against a matching reference. A separate PyTorch path supplies first-order material and regularized shape gradients with checkpoint replay, fused CUDA transposes and hierarchical host/file state storage. Ensemble APIs also evaluate independent structures concurrently. The formulation, software boundaries and numerical limitations are documented explicitly. A lossless dielectric slab provides an analytic validation of reflection, transmission and energy conservation. GPU throughput measurements include setup and data-transfer costs and distinguish one-device ensemble concurrency from single-simulation acceleration. The current implementation is a research workbench, not a feature-complete substitute for a commercial photonics platform.

\end{abstract}

\section{Motivation and scope}

Photonic simulation workflows combine geometry construction, broadband excitation, electromagnetic propagation and the extraction of observables. Repeating this sequence over many geometries is central to parameter sweeps and inverse design. A graphical editor lowers the cost of setting up a first model, while a programmable representation is essential for reproducibility and automation. TorchFDTD uses one validated scene model for both entry points. Every implemented native solver setting can be supplied without opening the user interface.

The implementation builds on the MIT-licensed \code{flaport/fdtd} package for its grid and backend foundation \citep{fdtd}. TorchFDTD supplies the derivative operators, boundary wrapping, CPML state, dispersive material update, mesh construction, monitor processing and execution orchestration described below. It uses NumPy for CPU calculations and PyTorch for CUDA arrays and graph capture \citep{pytorch-cuda,paszke2019}. These dependencies and their authors are acknowledged rather than presented as new work.

TORCWA demonstrates the value of pairing an electromagnetic formulation with GPU execution and a programmable design workflow \citep{kim2023}. It solves a frequency-domain Fourier modal problem and provides automatic differentiation. TorchFDTD advances a time-domain Yee discretization and provides first-order discrete adjoints through a PyTorch interface. Supported material and regularized analytic shape parameters connect to PyTorch optimizers. Bounded checkpoint replay and spatial streaming avoid retaining a full time-unrolled autograd graph. The independent forward ensemble optimizer remains available. No TORCWA code is incorporated. Equivalent design accuracy and end-to-end optimization performance require separate comparisons.

The forward solver includes two-dimensional z-invariant and three-dimensional models, analytic solids, isotropic dielectric and multipole dispersive materials, electric and magnetic vector soft sources, normal-incidence one-way planes and closed TFSF boxes, and point or planar frequency monitors. The differentiable path supports a narrower, explicitly documented set of sources, material models and observations. Periodic-layer response objectives support oblique Bloch incidence. Automatic decay termination and empirical mesh studies support selected forward observables. General eigenmode ports, near-to-far transformation, PMC and magnetic symmetry boundaries, rotated full material tensors, nonlinear materials and source-parameter adjoints remain incomplete. Physical shape-gradient mesh convergence is distinct from discrete adjoint correctness and remains a release requirement. A machine-readable feature inventory separates numerical, graphical and Python coverage.

\section{Scene model and software architecture}

The \code{Project} model contains a \code{Region}, a list of materials, structures, sources and monitors, and optional global source and monitor settings. Pydantic validation rejects unknown properties and non-finite values. Cross-field checks enforce grid dimensions, paired periodic boundaries, temporal Nyquist limits and source/monitor support within the non-PML region. Calling \code{Project.model_json_schema()} exposes the supported fields, enums and bounds.

The native model uses micrometres for geometry, wavelength and mesh spacing. Time is measured in seconds and frequency in hertz. Material oscillator parameters are angular frequencies. Bloch phase is specified in radians per unit-cell translation and carrier phase in degrees. An optional \code{FDTD} editing facade converts metre-based inputs to the same native project. These two length conventions are documented explicitly.

The browser edits a JSON representation of \code{Project}. The solver accepts the same representation and stores it with each NPZ result. Python export therefore represents the actual configured scene rather than a partial reconstruction of visible controls. Native simulation does not require a browser, a web server or any external simulation application.

Structure overlap is resolved before time stepping. A lower mesh-order integer takes priority, with the later object winning equal orders. Dielectric geometry that covers a dispersive region removes its oscillator ownership at the covered samples. The field image of permittivity represents the instantaneous relative permittivity, or $\epsilon_\infty$ for a dispersive material. It is not the full complex permittivity at a particular optical frequency.

\subsection{Analytic solids and rigid coordinates}

The solid model includes boxes, circular and elliptical cylinders, spheres and ellipsoids, full or partial elliptical rings, and extruded simple polygons. Polygon vertices define a local XY contour with a specified local z thickness. Both contour orientations and concavity are supported. Crossings, nonadjacent touching edges, adjacent overlapping edges and zero area are rejected. Polygon holes and general polyhedral surfaces remain outside this representation.

Let $\mathbf{c}$ denote the solid pivot and $R_a(\theta)$ a right-handed rotation about a fixed world axis. The local sample coordinate is
\begin{equation}
\mathbf{u}=R^\mathsf{T}(\mathbf{x}-\mathbf{c}),\qquad
R=R_{a_3}(\theta_3)R_{a_2}(\theta_2)R_{a_1}(\theta_1)R_z(\theta_{\mathrm{legacy}}).
\end{equation}
Ellipsoid membership is $\sum_a(u_a/r_a)^2\leq1$. A cylinder uses the transverse ellipse inequality and $|u_z|\leq L_z/2$. A ring subtracts an inner ellipse and optionally restricts the physical polar angle $\operatorname{atan2}(u_y,u_x)$. This is distinct from the ellipse parameter angle. A polygon uses an even-odd ray crossing test with explicit boundary inclusion. The two-dimensional solver samples the solid at $z=0$ and then assumes invariant field physics along z.

For each enabled solid, material preparation computes a conservative axis-aligned support, locates its grid-index intervals by sorted search and evaluates membership only there. A small floating-point padding retains samples on support boundaries. Box and ellipsoid support functions and polygon vertex extrema give their bounds. Partial rings retain the bound of their complete elliptical cylinder. Overlap order and dispersive ownership are then applied to the retained samples. This changes host preparation work without changing the Yee grid, time step or electromagnetic updates outside the solids. Browser tessellation is used only for display and never determines material membership.

Independent tests compare rotation composition with a separate rotation implementation, analytic concave masks and volume convergence. The finest tested midpoint spacing gives less than 1.2 percent relative volume error for six rotated solids. This volume check does not establish electromagnetic convergence at their interfaces. Equivalent rotated box and polygon representations produce bitwise-identical complete optical outputs. CPU, CUDA and shared-cohort tests also cover mixed new solids.

The independent layout importer maps recognized primitive records to the same native solid model. Polygon storage uses global unrotated XY vertices and a separate pivot, which are converted to local contour coordinates. Ordered rotations and physical polar ring sectors are retained. An existing-object writer splices only decoded fields into the original byte stream. Variable-length names and vertex arrays may shift later records, whose old and new offsets are reported. The output is reparsed and its geometry and material response are checked before a file is returned. A no-op edit preserves all bytes. Author-generated fixtures verify untouched segments, transformed geometry and equivalent native CPU, CUDA and shared-cohort calculations. These checks establish neither general file compatibility nor agreement with a commercial electromagnetic solver. Saved mesh nodes remain fixed. A scene writer additionally handles recognized source temporal definitions and phases, monitor frequencies and windows, duration, CFL, and a subset of PML and periodic settings. It updates controlling input properties together with resolved values. External automatic sampling may choose a finer temporal stride, and the export report discloses this limit. Native global apodization is represented by effective local windows. Object-list changes, groups, new dispersive coefficients and general physical settings remain outside this subset.

\section{Discrete electromagnetic formulation}

\subsection{Yee update and time convention}

The six field components occupy staggered positions \citep{yee1966}. Electric components lie at the midpoint of their own coordinate direction and on nodes along the transverse directions. Magnetic components use the complementary dual positions. In a nonmagnetic dielectric, the reduced-field update has the form

\begin{equation}
E^{n+1}=E^n+S\epsilon_r^{-1}\mathcal{C}^{-}(H^{n+1/2})+s^{n+1}.
\label{eq:electric-update}
\end{equation}

\begin{equation}
H^{n+3/2}=H^{n+1/2}-S\mathcal{C}^{+}(E^{n+1})+m^{n+3/2}.
\label{eq:magnetic-update}
\end{equation}

Here $S=c\Delta t/h$, $h$ is the smallest configured mesh step, and the curl operators contain dimensionless differences scaled by the appropriate metric. The soft electric source is added after the electric update and before the magnetic update. The implementation starts from zero fields. The first recorded electric sample is at $\Delta t$ and the corresponding magnetic sample is at $3\Delta t/2$. This convention must be retained in Fourier transforms.

For $d$ active spatial dimensions, let $h_a$ denote the minimum primal width on axis $a$. The conservative time-step limit is

\begin{equation}
\Delta t_{\max}=\frac{\eta}{c\sqrt{\sum_{a=1}^{d}h_a^{-2}}},\qquad 0<\eta\leq0.99.
\label{eq:timestep}
\end{equation}

An explicit positive override may select $\Delta t\leq\Delta t_{\max}$. Equal axis spacings recover $\eta h/(c\sqrt{d})$. The background and dielectric indices are restricted to values at least one. The static graded grid retains this conservative fine-grid time step. Coarsening a background without changing the minimum axis spacings reduces the number of cells while retaining the physical duration at fixed step count. It does not implement local time stepping or temporal subcycling.

The two-dimensional case suppresses derivatives along $z$ but retains all six vector components. An $E_z$ electric excitation produces the usual $\mathrm{TM}_z$ subsystem. Bloch configurations use complex arrays. Nondispersive and ADE updates operate with the same real or complex field dtype.

\subsection{Periodic and Bloch seams}

Each periodic direction contains $N$ independent cells. The code does not create a duplicated end plane. A Bloch field satisfies

\begin{equation}
F(x+L)=\exp(i\phi)F(x).
\label{eq:bloch}
\end{equation}

At a forward seam the difference uses $\exp(i\phi)F_0-F_{N-1}$. At a backward seam it uses $F_0-\exp(-i\phi)F_{N-1}$. The corresponding primal or dual spacing is applied to that difference. Source sheets can carry the same transverse Bloch phase. A point source in a periodic domain represents a periodically repeated source, which changes the physical problem from that of an isolated emitter.

\subsection{PEC and electric antisymmetry}

PEC planes lie at the declared mesh endpoints. At a lower plane the stored
tangential electric and normal magnetic components are zero. Production
initialization and validated source support preserve this invariant subspace
for the admitted diagonal material update. At an upper plane the missing
tangential electric node has the exact ghost value $E_t(N)=0$, giving
$(E_t(N)-E_t(N-1))/\Delta x_{N-1}=-E_t(N-1)/\Delta x_{N-1}$.
The transpose scatters the same signed coefficient back to its stored node.
Spatial tiles inherit this condition only at the true global boundary.
Electric antisymmetry uses the same parity. Subpixel coupling is not admitted.

FP32 checks compare discrete cavity eigenmodes and doubled periodic domains
for all axes and transverse polarizations. Resident real and complex CUDA,
material adjoints, spatial replay and CUDA cohorts use the same edge rule.
These checks do not establish PMC support. At an upper PMC plane the
tangential electric node is nonzero and needs an additional dynamic state,
together with its normal magnetic face and intersecting edge support.
Replacing it with the last interior sample would shift the physical wall.
PMC and magnetic symmetry therefore remain explicitly unsupported.

\subsection{Convolutional PML}

Each absorbing face has independent layer count, $\sigma$ scale, $\kappa$, $\alpha$ and polynomial exponents. The formulation follows convolutional PML \citep{roden2000}. Each transverse derivative in a PML segment owns a memory array $\psi$. The update is

\begin{equation}
\psi^{n+1}=b\psi^n+c_p D,\qquad \widetilde D=D/\kappa+\psi^{n+1}.
\label{eq:cpml-memory}
\end{equation}

\begin{equation}
b=\exp[-(\sigma/\kappa+\alpha)S],\qquad c_p=(b-1)\sigma/(\sigma\kappa+\alpha\kappa^2).
\label{eq:cpml-coefficients}
\end{equation}

The quotient is set to zero when its denominator vanishes. These are the code's dimensionless CPML coefficients, not a claim that similarly named controls in another solver have identical normalization. The depth profile, staggering and segment extents are explicit in \code{boundaries.py}. PML layers and the adjacent interior cell retain fine spacing on a graded grid.

Reflection depends on discretization, incidence, material continuation and profile parameters. The existence of a PML control does not establish a prescribed reflection tolerance. Relevant tests include periodic/Bloch identities, CPU/CUDA agreement and controlled boundary comparisons. General oblique, grazing and strongly dispersive PML convergence remains part of the validation roadmap.

\section{Passive dispersive materials}

The implemented frequency response uses the $\exp(-i\omega t)$ convention and up to 16 passive isotropic oscillators,

\begin{equation}
\epsilon(\omega)=\epsilon_\infty+\sum_{j=1}^{K}\frac{A_j}{\omega_{0j}^2-\omega^2-i\gamma_j\omega}.
\label{eq:dispersion}
\end{equation}

For a Drude term, $\omega_0=0$ and $A=\omega_p^2$. For the single Lorentz input model, $A=\Delta\epsilon\,\omega_0^2$ and $\gamma$ is twice the supplied linewidth. The multipole interface accepts $\omega_{0j}$, $A_j$ and $\gamma_j$ directly in angular SI units. Positive oscillator strength and nonnegative damping enforce the intended passive parameter range. This is not a measured-data fitting system, and the bundled constant-index Si, SiN and SiO$_2$ entries are labelled approximations.

The solver evolves polarization $P$ and the scaled current $Q=\Delta t\,\mathrm{d}P/\mathrm{d}t$ for each pole. Scaling avoids storing femtosecond-scale inverse-time magnitudes in float32 state. The oscillator equation and electric constitutive update are solved together by the trapezoidal rule. For a single pole, with old electric field $E_{\mathrm{old}}$, provisional nondispersive field $E_{\mathrm{free}}$, and current material state, define

\begin{equation}
d_0=1+\gamma\Delta t/2+(\omega_0\Delta t)^2/4.
\label{eq:ade-denominator}
\end{equation}

\begin{equation}
a=(\omega_0\Delta t)^2/2,\quad k=A\Delta t^2/(4d_0),\quad r=(Q-aP)/d_0.
\label{eq:ade-coefficients}
\end{equation}

\begin{equation}
E_{\mathrm{new}}=(\epsilon_\infty E_{\mathrm{free}}-kE_{\mathrm{old}}-r)/(\epsilon_\infty+k).
\label{eq:ade-electric}
\end{equation}

\begin{equation}
\begin{aligned}
\Delta P &= r+k(E_{\mathrm{new}}+E_{\mathrm{old}}),\\
P_{\mathrm{new}} &= P+\Delta P,\qquad Q_{\mathrm{new}}=2\Delta P-Q.
\end{aligned}
\label{eq:ade-state}
\end{equation}

Auxiliary states are allocated only for the final samples owned by that material. With physical Yee sampling, ownership and state follow individual electric components. With legacy cell sampling, all three electric components share the same cell material. The constitutive discretization has the bilinear frequency substitution $\omega\mapsto(2/\Delta t)\tan(\omega\Delta t/2)$. This response alone does not describe spatial Yee dispersion or interface discretization error.

For multiple poles, the coefficients $d_j$, $a_j$, $k_j$ and $r_j$ are evaluated separately and the common electric field is obtained from

\begin{equation}
E_{\mathrm{new}}=
\frac{\epsilon_\infty E_{\mathrm{free}}-(\sum_j k_j)E_{\mathrm{old}}-\sum_j r_j}
{\epsilon_\infty+\sum_j k_j}.
\label{eq:ade-multipole}
\end{equation}

Each pole then uses this common field in Eq.~\ref{eq:ade-state}. Applying single-pole electric corrections sequentially would not solve the coupled constitutive equation. The single-pole path retains its previous operation order. Passive fitting of sampled optical constants, anisotropy, magnetic dispersion, conductivity sheets, gain and nonlinear polarization remain absent.

\section{Rectilinear and graded meshes}

Uniform, graded and explicit node arrays are selectable. Uniform and graded generators accept independent minimum steps along the three axes. Explicit arrays must be finite, strictly increasing and centered on the native origin. Their endpoints define the domain, and geometry edits retain the arrays unchanged. All three representations use a tensor product. The graded algorithm projects geometry bounds, sources, monitor supports and refinement boxes into intervals on each axis. Refined intervals retain the corresponding fine lattice with two fine cells of padding. Cyclic seam cells and the PML support also remain fine.

Within an unrefined interval, a target spacing grows approximately linearly with distance from a refined edge, until limited by the user maximum and a background-wavelength cap. The node positions are equidistributed in the integral of the reciprocal target spacing,

\begin{equation}
u(x)=\int_{x_a}^{x}\frac{d\xi}{h_{\mathrm{target}}(\xi)},\qquad u(x_j)=j\,u(x_b)/N.
\label{eq:mesh}
\end{equation}

The gap constructor checks the minimum spacing, maximum spacing and adjacent-cell grading ratio. A short or incompatible gap falls back to uniform cells. It does not create a remainder cell smaller than the configured fine step. The default neighboring-cell ratio is 1.25 and the default background target is 24 cells per configured wavelength.

Forward derivatives use primal cell widths $h_i=x_{i+1}-x_i$. Backward derivatives use dual distances $(h_i+h_{i-1})/2$. Metric factors $h/h_i$ or their dual equivalents multiply the dimensionless differences, including periodic seams. An axis whose widths equal the reference step $h$ bypasses metric multiplication. This construction avoids hanging nodes, but a small refinement box refines coordinate planes across the entire simulation. It can save substantially fewer cells than a spatially local subgrid would.

Explicit and independent-axis grids evaluate CPML depth using physical node positions and the actual absorbing-layer extent. Source corrections use the local normal-axis spacing. One-way planes require a constant normal step across the injection neighborhood. Closed TFSF boxes require constant spacing along each axis throughout the box and adjacent cells, while allowing different spacings between axes. General nonuniform incident-line propagation is not implemented. Material updates and Fourier phases use the actual configured time step.

Independent tests initialize rectangular-grid Fourier waves from the discrete dispersion relation in three dimensions. Irregular periodic and Bloch grids also satisfy a weighted curl-adjoint identity. With electric weights formed from one primal and two dual widths, and the complementary magnetic weights, the vacuum leapfrog invariant is
\begin{equation}
\mathcal{E}^n=\|E^n\|_{W_E}^2+\|H^{n+1/2}\|_{W_H}^2+
S\operatorname{Re}\langle E^n,\mathcal{C}^-H^{n+1/2}\rangle_{W_E}.
\end{equation}
The numerical test preserves this quantity within $5\times10^{-13}$ relative over 240 updates on independently generated positive node widths. This test excludes sources, materials and absorbing boundaries. Separate source-line and variable-depth PML pulse tests cover those stated configurations. Stability and these identities do not establish a general spatial accuracy bound.

Material assignment can sample either common cell centres or the separate physical Yee positions. The latter usually provides a more faithful interpretation of component placement, but it is still a staircase interface. No conformal integration or subpixel averaging is present. A coarser background mesh is a resolution heuristic, not an a posteriori error estimator. Metal skin depth, small gaps and resonant near fields require explicit convergence studies.

\subsection{Empirical mesh convergence}

The Python \code{mesh_convergence} routine rebuilds the same physical scene at decreasing spacings. It preserves the actual domain spans and PML thickness, rejecting spacings that cannot represent them as integer cell counts. The number of steps changes to preserve the original physical duration with less than one timestep of rounding. For a matched reference, the graded refinement intervals are frozen from the sample. Automatic decay termination is disabled during the study to keep sample and reference integration times identical.

The user supplies a finite real observable, such as a reference-normalized transmission spectrum on a fixed frequency grid. Success requires the final configured number of consecutive comparisons to satisfy the stated absolute and relative tolerances at every returned value. A cancelled study or invalid observable does not report convergence. Agreement of successive meshes is an empirical test for the chosen observable, not a general error bound or an adaptive mesh algorithm.

\section{Termination and state diagnostics}

An optional decay rule monitors the complete electric and magnetic fields and passive oscillator states. A positive diagnostic norm combines cell-volume-weighted field squares with each material term

\begin{equation}
\frac{|Q_j/\Delta t|^2+\omega_{0j}^2|P_j|^2}{A_j}.
\label{eq:diagnostic-state}
\end{equation}

The field term weights electric components by their instantaneous relative permittivity. This is a stopping heuristic, not a conserved discrete electromagnetic energy. CPML memories are checked for non-finite values rather than included as positive stored energy. A single displayed field slice cannot replace the complete-domain check.

Decay checks become eligible only after every finite source has finished its specified tail or sampled table, plus any extra waiting time. A continuous source disables decay termination. The observed maximum norm is frozen at the first eligible check, and the norm ratio must stay below the requested threshold for several consecutive checks. Non-finite state, an optional absolute field ceiling and a post-source growth limit report failure. Successful decay termination is distinct from user cancellation, so batch objectives still evaluate normally.

On CUDA systems with CuPy, two read-only kernels reduce array segments and then combine their partial sums. Values are promoted before squaring, including complex and weak float32 fields. This avoids full-domain double-precision copies and many small tensor launches. The NumPy and Torch implementations provide reference paths. Host diagnostic-call time includes synchronization with preceding GPU work and is not an isolated kernel timing. A full-duration checked and unchecked comparison measures actual overhead.

A truncated current pulse with nonzero time integral can leave electrostatic charge and prevent a strict decay condition. Tightening or loosening termination cannot correct the source definition. Automatic termination also does not establish Fourier convergence, especially for long-lived resonances. A longer fixed-duration calculation remains an independent temporal check.

For a reference calculation, automatic refinements can be frozen into manual boxes before removing the structure. This keeps the sample and reference node arrays identical. Mesh-dependent response changes must not be mistaken for material transmission. Exact axis nodes are retained in NPZ output. Browser field snapshots are resampled for physical-coordinate display and should not be used as a substitute for those arrays.

\section{Sources and frequency-domain observables}

\subsection{Excitation and point traces}

Electric and magnetic soft sources can be point-like or sheet-like. A sheet radiates in both directions and is not a one-way plane-wave source. Supported time waveforms include Gaussian pulses, continuous excitation, automatic broadband definitions and sampled time/amplitude/phase tables. Global source inheritance preserves local geometry, orientation and amplitude controls. Source amplitudes are reduced field increments and are not calibrated dipole moments or SI field strengths.

Cartesian excitation selects one E or H component. A vector source selects the field family and a unit direction
\begin{equation}
\boldsymbol{u}=(\sin\theta\cos\phi,\sin\theta\sin\phi,\cos\theta).
\end{equation}
Theta is measured from the positive z axis and phi from positive x toward positive y. Each component receives the shared waveform multiplied by its signed direction weight. Exact cardinal angles have exact zero components, while intentionally weak components at other angles are retained. Separate Cartesian sources with different phases can represent elliptical excitation. One theta/phi source has one common phase.

The electric increment is applied after the E update at time $n\Delta t$. The magnetic increment is applied after the H update at $(n+1/2)\Delta t$. Both precede monitor recording. Each vector component uses its own Yee coordinates for nearest-site placement, sheet support and Bloch phase. One requested CAD position therefore remains represented on staggered sites, which requires mesh convergence for near-field source observables. The CPU, CUDA graph, real fused CUDA and tensor-cohort paths share these conventions.

Point monitors record one selected field component at every time step. An FFT amplitude convention is retained for legacy plots. Explicit-frequency DFT uses

\begin{equation}
\widehat F(f)=\Delta t\sum_n w(t_n)F(t_n)\exp(2\pi i f t_n).
\label{eq:dft}
\end{equation}

Electric and magnetic traces use their actual sample times. None, start, end and full Gaussian apodization are available. Hann is retained for point FFT workflows. Windowed field integrals are not automatically normalized powers. Uniform frequency, uniform wavelength, explicitly supplied tables, interior Chebyshev roots and Lobatto endpoints are supported. The sampling definitions and inherited settings are specified below.

\subsection{Normal-incidence one-way planes}

A separate source option applies paired electric and magnetic corrections at a planar total-field/scattered-field interface. This is an application of the equivalent-current principle \cite{oskooi2013sources}. The current implementation supports all active Cartesian propagation axes, either direction and transverse electric polarization. The plane fills a periodic transverse unit cell. Its neighboring samples must have the nondispersive background index and uniform fine spacing. Graded cells and dispersive structures are permitted away from the interface.

The incident fields are prepared on a scalar one-dimensional Yee line with the same timestep, fine mesh and background index $n_b$. The selected soft electric waveform drives this line eight cells before the probe. With $L$ CPML cells at each end, the line contains $2L+64$ cells. The default is $L=96$, with a configurable range from 32 to 512. For propagation in the positive normal direction, total-field E samples start at index $k$. After the E update and before the H update, the electric correction is
\begin{equation}
\delta E_k^{n+1}=\frac{S}{n_b^2}h_{k-1}^{\mathrm{inc},n+1/2},
\qquad
\delta H_{k-1}^{n+3/2}=S e_k^{\mathrm{inc},n+1},
\end{equation}
where $S=c\Delta t/h$ and scalar H is oriented along the normal crossed with the electric polarization. The magnetic correction is applied after the H update. Negative propagation mirrors the interface and reverses the magnetic orientation. The prepared arrays are shared by the CPU, CUDA and tensor-cohort source paths.

The eight-cell delay and incident-line numerical dispersion are retained. Amplitude scales the auxiliary drive rather than prescribing unit incident E or calibrated power. Finite auxiliary CPML introduces residual source error, so the incident PML size requires convergence checks for weak scattering. The side toward propagation stores total fields, while the opposite side suppresses the incident wave. Oblique incidence, finite apertures and mode selection are not implemented by this option. Recognized three-dimensional normal-incidence FSP plane records have a native mapping, with general source conventions remaining open.

\subsection{Closed total-field/scattered-field boxes}

A closed box extends the equivalent-current construction to isolated scatterers. Let $M_E$ and $M_H$ select samples inside the box at their respective Yee coordinates. The required corrections to the ordinary field update are
\begin{align}
\delta E &= \frac{S}{n_b^2}\left[M_E\mathcal{C}^{-}(H_i)
                         -\mathcal{C}^{-}(M_H H_i)\right],\\
\delta H &= -S\left[M_H\mathcal{C}^{+}(E_i)
                         -\mathcal{C}^{+}(M_E E_i)\right].
\label{eq:tfsf-commutator}
\end{align}
The incident fields $E_i,H_i$ solve the homogeneous discrete problem. The mask differences vanish away from the box faces. The implementation therefore stores sparse correction indices and weights with surface-sized memory, combining corner contributions before execution. Samples inside the staggered box contain total fields and samples outside contain scattered fields.

For normal incidence, a live scalar Yee line contains $2L+64+N_a$ cells, where $N_a$ is the box span along propagation in cells. It retains the eight-cell drive-to-entry delay and uses the same fine spacing, timestep and background index as the main grid. Unlike a time-by-surface table, its auxiliary field storage grows with the normal span and PML thickness. A separate scalar drive table grows with the step count. The source requires a homogeneous nondispersive shell, uniform fine cells around the box, and exterior PML on every active axis. Dispersive scatterers may lie strictly inside and graded cells may lie outside the refined neighborhood. Oblique incidence and layered incident media remain unsupported. Recognized three-dimensional normal-incidence FSP TFSF records have a native mapping, with general source conventions remaining open.

The fused CUDA E phase advances the auxiliary E field and corrects the main E faces in one launch, with both operations reading the previous auxiliary H. The H phase similarly reads the new auxiliary E. There is no cross-block dependence on an array being updated in the same launch. Separate source ordinals preserve ordering for overlapping boxes, while independent cases share the second launch dimension. Graph reset clears all auxiliary fields and CPML memory. A positive area-weighted norm of the complete incident line participates in decay diagnostics, preventing termination while an incident pulse remains in transit.

\subsection{Plane monitors and Poynting flux}

A frequency plane monitor can record selected electric, magnetic and Poynting components, together with signed flux. The default retains all six field components. For a 3D plane, transverse integration bins span the requested physical rectangle. For 2D, the line integral represents power per invariant length. Independent transverse strides merge integration bins while preserving their total measure. Every required component is interpolated from its own Yee locations onto the common quadrature points, including Bloch phase when an interpolation stencil crosses a cyclic seam. The normal coordinate can be the specified position or the nearest native mesh node.

The electric DFT samples use $t=(q+1)\Delta t$. The corresponding magnetic DFT adds a half-step phase factor $\exp(i\pi f\Delta t)$. Separate apodization weights use the actual $E$ and $H$ times. Online accumulators retain complex values for each frequency, point and component. They are included in CUDA Graph reset state, so warm-up or capture does not contaminate the recorded spectrum.

After transferring to host complex128 arrays, the code evaluates

\begin{equation}
\begin{aligned}
\mathbf{S}(f)&=\frac{1}{2}\operatorname{Re}\!\left[\widehat{\mathbf{E}}(f)\times\widehat{\mathbf{H}}(f)^*\right],\\
\Phi(f)&=\sum_j A_j\,\mathbf{S}_j(f)\cdot\hat{\mathbf{n}}.
\end{aligned}
\label{eq:flux}
\end{equation}

Host promotion avoids underflow when products of femtosecond-scale DFT integrals are multiplied by square-micrometre areas in float32. The raw quantity is reduced spectral flux. It is not a calibrated watt value. The monitor normal is the positive coordinate direction, so a reflected wave can have negative signed flux.

The accumulator channels are the dependency union of requested outputs. A single stored field requires one channel. Flux along $x$ requires $E_y,E_z,H_y,H_z$, even when no fields are exported. The analogous cyclic subsets determine flux along the other axes. This reduces a flux-only plane from six to four complex channels without changing its integration points or timestamps. Stored field and Poynting arrays carry explicit component names. Omitted channels have empty axes and absent flux is represented separately, so missing data cannot be mistaken for a measured zero.

An optional complex128 accumulator retains float32 field evolution. Spatial interpolation and multiplication by the apodization weight still use field precision. It improves accumulator precision only and does not recover field accuracy lost during propagation. CUDA planes with different accumulator precisions form separate launch groups.

For a temporal stride $s$, the retained indices are $q=0,s,2s,\ldots$ and the integration weight becomes $s\Delta t$. Electric and magnetic timestamps remain $(q+1)\Delta t$ and $(q+1.5)\Delta t$. The CUDA observer skips gather and accumulation at other steps, while field evolution and point traces remain unchanged. Requested frequencies are checked against $1/(2s\Delta t)$. No antialias filter is applied, so the actual signal must also have negligible content above that limit. This decimation changes quadrature and is excluded from the exact-output comparisons below.

Frequency sampling supports uniform frequency, uniform wavelength, custom positive increasing tables and two Chebyshev conventions. Interior roots use $u_i=[1-\cos(\pi(i+1/2)/N)]/2$. Lobatto nodes use $u_i=[1-\cos(\pi i/(N-1))]/2$ for $N>1$, with a midpoint when $N=1$. The interval is interpolated in the chosen frequency or wavelength coordinate. Global frequency settings can be inherited independently of local apodization. Source-bound intervals use the union of explicitly ranged enabled sources. Other pulse definitions require explicit monitor limits.

\subsection{Reference normalization}

Normalized transmission divides sample flux by the absolute flux of a matching reference. Reflection first subtracts the complex reference $E$ and $H$ fields, then evaluates the scattered-field Poynting flux. Subtracting two already integrated powers would retain interference terms and is not equivalent.

A run signature checks region settings, source definitions, completed time-step count and exact nodes. Monitor coordinates, weights, frequency samples, temporal strides and normals must also match. Apodized normalization is rejected. By default, frequencies with reference flux below one percent of the reference maximum are invalid and return NaN ratios. Users must preserve monitor IDs and freeze automatic graded refinements when constructing an air reference. Flux-only results support direct ratios. Incident-field subtraction requires storing the four tangential fields in both runs and rejects missing channels.

This method supports controlled surface-flux ratios. It does not automatically establish a mode-resolved scattering matrix, a closed-surface absorption result, a far-field radiation pattern or an absolute collection efficiency. Those quantities require additional operators and validation.

\section{CUDA execution and independent simulation ensembles}

\subsection{One simulation}

All field, CPML and material-state arrays remain on the selected GPU during time stepping. Sources are tabulated on the actual time grid and monitor indices are prepared before execution. A complete step can be captured in a PyTorch CUDA Graph. Three warm-up steps and graph capture are followed by an explicit reset of fields, source counters, traces, CPML memory, material state and frequency accumulators. The captured graph then replays the same tensor operations with a device-resident step counter.

Snapshots transfer only the selected plane at a bounded interval. Final E/H arrays and frequency-monitor data are transferred at completion. Timings distinguish setup from the synchronized stepping loop. End-to-end ensemble measurements additionally include geometry voxelization, graph capture, result transfer and worker communication. A stepping-loop speedup is not an end-to-end application speedup.

\subsection{Batch scheduling}

The inherited backend changes process-global state. Threaded concurrent simulations in the same process are therefore unsafe. \code{BatchRunner} uses spawned processes, each with its own solver state and CUDA context. \code{parameter_sweep} creates a Cartesian product of validated parameter assignments. \code{BatchCase} can also hold an entirely different project, allowing heterogeneous meshes, materials and monitor layouts in one ensemble.

Before submission, the runner estimates the largest case and admits a bounded number of workers per device. A worker reservation is 1.5 times the solver memory estimate plus 768 MiB for GPU context and allocator overhead. The default aggregate GPU budget is 60\% of currently free memory. Idle workers release unused allocator blocks, while their process contexts may persist across optimizer generations. A user memory cap can impose a stricter limit. This admission estimate cannot prevent another application from consuming memory later.

Multiple device IDs assign independent cases to multiple GPUs. The current tests establish single-GPU process concurrency, not multi-device performance. This method is neither single-grid MPI decomposition nor a fused tensor batch. Different CUDA contexts may serialize kernel execution on one device. Increasing the worker count can therefore reduce throughput, and the benchmark must decide the useful setting for a given problem.

Each result records its case ID, parameters, status, worker PID, device, timings and metrics. Saved NPZ data is accompanied by a checksum and a fingerprint of the project and package source. Resume requires matching fingerprints, unchanged objective version keys and valid file checksums. The optimizer can therefore reuse matching completed evaluations without silently accepting stale geometry or changed objective definitions.

\subsection{Black-box inverse design}

The \code{optimize} function implements bounded DE/rand/1/bin \citep{storn1997}. Three distinct population members, excluding the target, define a mutant. A binomial crossover mask includes at least one forced dimension. Trial parameters are clipped to bounds and evaluated as a parallel population. A trial replaces its target when it is no worse under the selected minimization or maximization convention.

Objectives are ordinary module-level Python callables receiving the complete simulation result. They return a finite scalar or named scalar metrics. Evaluation occurs in the worker, avoiding transfer of large field arrays merely to compute a scalar. A fixed random seed and stored generation configuration make the proposal sequence reproducible. Failed simulations and invalid objective values stop the optimization explicitly rather than masquerading as physically valid candidates.

The included cylinder example maximizes a local unnormalized spectral intensity. It illustrates orchestration and does not claim a validated collection-efficiency optimum. No gradient is differentiated through the time loop, no global-optimum guarantee is provided, and fabrication constraints beyond parameter bounds are left to the project construction. Final designs require an independent mesh/time convergence check and a physically justified figure of merit.

\subsection{Fused real-field Yee and CPML kernels}

The optional fused CUDA path specializes two kernels to the grid shape, dtype, boundary topology and metric. Each thread computes one cell's three output components. The electric kernel forms the backward curl from H, updates the relevant CPML slab memory and writes E. The magnetic kernel forms the forward curl from the updated E and writes H. Electric source injection follows the E launch, and magnetic injection follows the H launch. Their shared CUDA stream supplies the global ordering required by the Yee leapfrog update. This is spatial operation fusion within each update, not temporal blocking across several time steps.

Unlike the tensor reference, these kernels do not materialize full-volume derivative or curl arrays. Each CPML memory array retains only its boundary slab. Periodic seam indices and graded primal/dual metric factors enter the same derivative formulas. The existing sparse ADE correction retains its implementation. Frequency monitors have a separate optional shared CUDA path described below. Bloch complex fields remain on the tensor path. Neither the new kernels nor CUDA graph replay provide an adjoint.

Torch owns the field, coefficient and state storage. DLPack supplies zero-copy CuPy views \citep{cupy-dlpack}, and the launches use the active Torch CUDA stream. In-memory NVRTC compilation avoids filesystem-dependent source paths. Compiler options disable fused multiply-add contraction and preserve subnormal values. An initial compiler configuration flushed weak float32 fields to zero and failed the full-field comparison. The revised configuration passes that comparison and a dedicated subnormal regression. Compilation occurs before graph capture, and module lifetimes cover all captured executions.

\subsection{Shared CUDA launches for independent structures}

The \code{run_tensor_batch} API maps independent cases to the second CUDA block-grid dimension. The first dimension indexes spatial cells. For a block width of 256, the cell and case indices are
\begin{equation}
i=256\,\mathrm{blockIdx.x}+\mathrm{threadIdx.x},\qquad b=\mathrm{blockIdx.y}.
\end{equation}
A device pointer table selects each case's fields, material coefficients and CPML memory. The electric and magnetic stencil bodies are generated by the same code as the independent fused solver. No stencil reads another case's state. Separate shared E and H source launches assign non-overlapping source samples at the corresponding update stages. A shared point-monitor launch records each case before incrementing the common time index. ADE corrections retain per-case operations between these launches. Planar frequency accumulation can use the reference operations or the shared implementation below. CUDA graph capture resets every case's mutable state.

This implementation supports real float32 and float64 fields, two and three dimensions, matched uniform or graded grids, periodic boundaries, face-specific CPML and passive multipole materials. A cohort requires common nodes, precision, timestep, step count and boundary topology. Geometry and material values may differ. Complex Bloch fields, overlapping source supports and per-case automatic decay termination are explicitly rejected. A numerical failure aborts the cohort, while an invalid scalar objective marks the affected result as failed.

An explicit \code{cohort_size} partitions an ensemble into consecutive groups of at most 64 cases. The final partial group is allowed. This controls resident device state and can improve throughput when a large batch performs poorly. It does not limit accumulated host arrays when results are retained. The differential-evolution driver can evaluate each population through these shared launches by selecting tensor execution. Process execution remains the default. Both paths use the same proposal and replacement rules. Checksum resume, process fault isolation and heterogeneous resources remain features of the process runner.

A separate \code{run_grouped_batch} scheduler accepts interleaved projects with different meshes, durations, boundaries or real precisions. It computes the same exact topology signature used by the tensor executor and retains first-appearance order among groups. Each group is partitioned by an explicit cohort-size cap and the native memory estimate. No padding, resampling, precision change or shortened trajectory is introduced. Groups execute successively on one GPU, while cases within each cohort share CUDA launches. Results are returned in input order, but objective callbacks follow execution order. The plan reports this distinction and the original case indices. Complex fields and per-case automatic termination are rejected. This scheduler does not add an adjoint or automatic heterogeneous routing to the differential-evolution driver.

The optional \code{tune_tensor_batch} routine measures complete workloads for candidate cohort sizes. One warmup precedes repeated alternating measurements. Each solve includes preparation, graph capture, time stepping and final result transfer. Source duration and physical outputs are unchanged. Hash comparisons require bitwise equality of the native fields, traces, snapshots, permittivity and frequency-plane arrays across candidates. The routine does not evaluate user objectives or save simulation results. Memory-admission rejections remain in the report, while other failures stop selection.

The selected size minimizes the observed median full-solve time. The report separately records the complete tuning cost, including warmups and output verification. Selection is explicit rather than hidden in a simulation call. It can be reused for similar design generations, but does not guarantee the fastest size on a later workload. A later independent timing series assesses that limitation. Host-side case inspection is scheduled only at requested diagnostic and snapshot steps, preserving observation order while avoiding a scan over the complete cohort on every step.

\subsection{Shared spatial interpolation and frequency accumulation}

The independently selectable \code{cuda_monitor_kernel} retains the reference plane coordinates, quadrature weights and component-specific interpolation maps. Its first kernel computes a real sample for each point $j$ and component $c$,
\begin{equation}
u_{jc}^{q}=w_c(t_q)\Delta t\sum_{\ell=1}^{K} a_{jc\ell}F_c^q[I_{jc\ell}],
\end{equation}
where $K=4$ in two dimensions and $K=8$ in three dimensions. Electric and magnetic components use their own apodization times. A second kernel assigns each frequency, point and component to one thread and accumulates
\begin{equation}
\widehat F_{fjc}^{q+1}=\widehat F_{fjc}^{q}+p_{fc}^{q}u_{jc}^{q}.
\end{equation}
The electric phase is $\exp[2\pi if(q+1)\Delta t]$. The magnetic phase includes the existing additional half-step factor. The initial implementation evaluates the double-precision exponential through Torch, followed by complex64 or complex128 conversion and magnetic phase multiplication. The current implementation adds a preceding CUDA phase kernel. One thread per frequency evaluates double-precision sine and cosine at the absolute time index, converts the result to the requested precision and applies the magnetic factor. Planes with matching frequencies and timesteps share a phase buffer with one writer per frequency. There is no recurrent phase multiplication, so phase rounding does not accumulate across steps. The previous Torch expression remains available for controlled ablation.

The second block-grid coordinate chooses a plane across one or more independent cases. Pointer tables retain separate field arrays, interpolation maps, windows and accumulators. No atomic operation or inter-case reduction is required. The additional scratch storage is one real value per required field and plane point, without a volume time history or time-by-frequency table. Metadata specifies each plane's channel count, electric-channel count and temporal stride. Every scratch value is overwritten before use, while persistent DFT accumulators participate in the usual graph reset.

The option supports real float32 and float64 fields on uniform or graded meshes with periodic or CPML boundaries. Complex Bloch fields retain the reference monitor path. Observation does not change the Yee updates or material state. The interpolation sum can have a different rounding order from Torch, so complete complex spectra are compared with a declared tolerance. Fused independent and fused cohort spectra must agree bitwise. The default monitor implementation remains the Torch reference.

\subsection{Graph unrolling with observation barriers}

The optional \code{cuda_graph_steps} execution parameter captures a single-step graph and a second graph containing up to 64 consecutive unchanged steps. Independent private graph pools permit either graph to be replayed next \citep{pytorch-cuda}. Both captures reset all mutable Yee, CPML, ADE, auxiliary-line, trace and DFT state. Every step retains its original source samples and monitor accumulation. This reduces host replay calls without changing the physical timestep or performing shared-memory temporal blocking.

The scheduler treats every requested snapshot, diagnostic and progress callback as an exact barrier. It replays the larger graph only when the full chunk fits before the next barrier, then uses single-step replays for a shorter remainder. Single-run decay termination therefore observes the original sequence of eligible checks and stops at the same step. Tensor execution still requires fixed-duration runs. Cancellation is polled between graph replays and can have a polling interval of the selected chunk size. Frequent host observations can prevent unrolling. The default is one step because capture time and additional graph storage may outweigh loop savings.

\subsection{Differentiable radiation transforms}

Periodic diffraction analysis Fourier-projects collocated E/H fields over
one complete rectangular cell. If $\mathbf e$ is tangential electric field
and $\mathbf q=-\widehat{\mathbf n}\times\mathbf H$, directional amplitudes
are $\mathbf e_\pm=(\mathbf e\pm\mathbf Y^{-1}\mathbf q)/2$, with
$\mathbf Y=(k_n\mathbf I+\mathbf k_t\mathbf k_t^T/k_n)/k_0$.
Evanescent orders retain complex amplitudes but no individual directional
real power. Grazing cutoff is rejected with a precision-aware tolerance.
Matched-reference power ratios preserve both field graphs and use common
detached scales before multiplying SI-scale DFT fields and areas.

For isolated radiation, six closed-box planes supply equivalent currents
$\mathbf J=\widehat{\mathbf n}\times\mathbf H$ and
$\mathbf M=-\widehat{\mathbf n}\times\mathbf E$. The outgoing amplitude is
\begin{equation}
\mathbf E_\infty(\widehat{\mathbf s})=
\frac{ik}{4\pi}\int_S
\left[\frac{(\mathbf I-\widehat{\mathbf s}\widehat{\mathbf s}^{T})\mathbf J}{n}
-\widehat{\mathbf s}\times\mathbf M\right]
e^{-ik\widehat{\mathbf s}\cdot(\mathbf r-\mathbf r_0)}\,dS .
\end{equation}
Here $n$ is the fixed exterior refractive index and relative permeability is
one. All faces must lie in the same lossless isotropic exterior, outside PML.
The integral does not implement layered-background or periodic lattice
Green functions. Fixed scalar propagation phases use double precision before
casting to the field precision, avoiding macroscopic-distance phase rounding.

A translated analytic vector dipole verifies complex amplitude, polarization,
surface-quadrature convergence and integrated power. A native material VJP
for a radiation objective agrees with central differences. In a separate
native FP32 dipole calculation, fixed physical domain, PML thickness and
approximately fixed duration give normalized angular-pattern relative
$L_2$ errors of $1.0314\%$, $0.5412\%$ and $0.2304\%$ at mesh spacings
of 100, 75 and 50 nm. This establishes one vacuum radiation limit, not absolute
source-power calibration or convergence of every radiation gradient.

Stored native frequency planes also feed these transforms without another
time-domain solve. The browser diffraction workflow requires six complex
field components, complete uniform unit-cell quadrature and an explicitly
declared homogeneous lossless exterior. Raw directional powers remain
distinct from efficiencies, which require a matching incident reference.
Evanescent and grazing-cutoff orders are distinguished. A bounded NPZ adapter
reads the selected monitor without loading full-domain fields or snapshots.
These saved-data operations have no retained simulation graph. Direct
differentiable-plane inputs continue to expose the radiation VJP.

\subsection{Bulk tensor constitutive operator}

A separate experimental periodic-domain API admits a real symmetric physical
permittivity tensor at each common mesh node. The electric components at one
array index occupy different Yee edges, so a colocated matrix multiplication
does not define the constitutive update. Instead, let $R_{ns}$ gather one of
the eight triplets of incident electric edges at node $n$, including Bloch
seam phases, and let $K_n=\epsilon_n^{-1}$. The bulk inverse operator is
\begin{equation}
S=\frac18\sum_{n,s}R_{ns}^{\dagger}K_nR_{ns} .
\end{equation}
Every bulk node participates. This differs from the interface-candidate
operator used for isotropic subpixel homogenization. Complete periodic
coverage gives $\frac18\sum_{n,s}R_{ns}^{\dagger}R_{ns}=I$. Consequently,
the admitted spectral condition $\epsilon_n\succeq I$ implies $0\prec S\preceq I$
and preserves the conservative vacuum CFL bound on the rectangular grid.
Matrix-free gather and scatter avoid a dense global constitutive matrix.

The electric update applies $S$ to the native magnetic curl. Its transpose
applies the same Hermitian operator to the electric cotangent. Tensor
derivatives follow
\begin{equation}
\delta S=-\frac18\sum_{n,s}
R_{ns}^{\dagger}K_n\,\delta\epsilon_n\,K_nR_{ns} .
\end{equation}
The implementation projects the real material gradient onto symmetric
tensor variations. It reuses the bounded native checkpoint schedule and
point or online-DFT observations. Geometry construction, source parameters,
Bloch phases and observation coordinates remain fixed in this API.

For a constant tensor, an independent staggered Fourier calculation gives
$S_{aa}(\mathbf q)=K_{aa}$ and
$S_{ab}(\mathbf q)=K_{ab}\cos(q_a/2)\cos(q_b/2)$ for $a\ne b$.
Tests compare the full vector update to this symbol, check all six symmetric
material directions by central differences, and verify real and complex FP32
CPU/CUDA trace and gradient agreement. A bounded FP64 Fourier diagnostic
preserves modified leapfrog energy over 256 steps within $2\times10^{-12}$.
Three mesh refinements approach the continuum dispersion with approximately
second-order error. These checks establish a periodic nondispersive bulk
foundation. Anisotropic interface accuracy, tensor ADE, modal injection,
spatial streaming and optimized fused tensor kernels remain unvalidated.

The native material workflow accepts the six symmetric Cartesian entries
in the browser editor and serialized Python projects. A bounded fixed-node
ownership map gathers a differentiable material table into the tensor field.
This connects all six material entries to the checkpointed field objective,
without claiming shape differentiation of hard geometry membership.
Native CPU/CUDA execution retains point traces, snapshots and NPZ fields.
Independent periodic and Bloch Fourier-symbol tests also exercise this
project-level path. Small periodic, Bloch and fixed-collar CPML cases have
maximum CPU/CUDA trace and material-table VJP differences of
$9.31\times10^{-10}$ and $1.00\times10^{-11}$, respectively.
These are workflow correctness checks, not large-domain timing results.

A subsequent extension encloses interior anisotropic material in a fixed
isotropic CPML exterior. Nonperiodic gathers use zero extension instead of
coupling opposite faces. Defining the diagonal coverage operator
$D=\frac18\sum_{n,s}R_{ns}^{\dagger}R_{ns}$ gives the normalized assembly
\begin{equation}
S=D^{-1/2}\left(\frac18\sum_{n,s}R_{ns}^{\dagger}K_nR_{ns}\right)D^{-1/2}.
\end{equation}
This preserves the constant diagonal limit and the local positive-definite
bounds at finite edges. The CPML derivative is applied before $S$, and the
reverse pass includes every CPML auxiliary state in the correct reverse
order. An explicit isotropic background is required throughout the PML and
one additional nodal row enclosing the constitutive stencil. That collar
is fixed and its material gradient is zero. Independent tiny-matrix and
full-state autograd checks, including nonzero auxiliary states, verify the
admitted algebra. Real and complex FP32 CUDA material gradients match the
CPU reference. A fixed 64-matrix batch for eigenvalue validation bounds a
previously excessive CUDA workspace. General anisotropic PML matching,
long-time reflection and stability, and interface accuracy remain open.

A separate normal-incidence acceptance uses a $0.6\,\mu$m slab with
transverse principal indices 1.5 and 2.0, rotated by $25^\circ$, inside an
index-1.2 exterior. Independent polarized transfer-matrix coefficients
provide the continuum reference. Normal spacings of 50 and 25 nm preserve
the slab thickness, 1 $\mu$m PML and approximately 80 fs duration. The FP32
complex transmission-vector errors are 1.0088 and 0.2421 percent. The coarse
rotation derivative of cross-polarized transmitted power is 0.556635 per
radian, compared with the continuum value 0.548367. The 1.5077 percent
derivative error and both transmission results pass their predeclared
criteria. This experiment uses the negative-exponent history-spectrum
convention, with the continuum phasor chosen consistently. The four forward
solves and one checkpointed backward take 54.56 s on RTX 3060. These results
validate this fixed-exterior slab observable. They do not isolate PML
reflection or establish oblique-incidence and long-time stability.

\subsection{Endpoint and distributed checkpoint foundations}

Exact PMC walls require upper electric face and edge samples and upper normal
magnetic samples omitted by the original volume-only Yee arrays. The bounded
endpoint API stores these degrees of freedom once, samples material at their
physical coordinates, and injects electric point waveforms between the
electric and magnetic substeps. Real FP32 CPU and direct CUDA paths return
point traces with sampled-material and waveform derivatives. No endpoint
material is implicitly copied from an interior cell. Independent reference
tests cover mixed walls, nonuniform metrics and upper-edge objectives.

The reverse pass uses a fixed number of resident checkpoints and a binomial
replay schedule. A logical 10,000-step schedule with four slots requires
115,061 replayed forward steps, compared with 49,995,000 with no slots.
This is a schedule count without fields, not a measured GPU acceleration.
A separate 31-step field test checks the live-slot bound and gradient.
Field storage is independent of duration at fixed checkpoint count, while
waveform inputs and point-trace outputs still scale with duration and are
included in admission. ADE, streamed endpoints
and large-domain throughput remain separate gates.

A separately scoped Project adapter samples native analytic solids at every
endpoint electric coordinate, applies native pulse and polarization settings,
and records requested and selected Yee positions. Its closed-wall override
is explicit and does not alter the general Project boundary schema.
Optional sampled material and waveform tensors retain their gradients.
This connects fixed CAD geometry to the endpoint API. Broader source and
monitor types remain unimplemented.

The subsequent native dispatch accepts the same closed-cavity subset in
ordinary Project JSON, CLI and browser execution. The browser validates all
six proposed face edits atomically. Point traces and volume plots use the
usual result interface, while NPZ additionally preserves the true upper
face and edge samples. Calculated tensor and host requirements are admitted
against available memory instead of imposing a fixed small GPU capacity.
Independent CPU and CUDA results and the complete browser export/run flow
are checked. ADE and streamed endpoint propagation remain outside this
native adapter.

A separate uniform-grid endpoint extension combines PMC with CPML terminated
at PEC walls. Each curl derivative owns auxiliary samples at its actual
target Yee positions, including intersections with upper PMC faces and edges.
The update order is electric field and auxiliary state, electric source,
then magnetic field and auxiliary state. The transpose reverses this order
and includes future auxiliary cotangents in the waveform derivative.
All auxiliary states participate in bounded checkpoint replay. The admitted
PML and one-cell material collar are fixed, scalar and isotropic.

An independently assembled CPU recurrence checks the full state transpose
and material and waveform VJPs. A 240-step pulse in a full CPML domain and
its PMC-reduced half agrees at every corresponding E/H sample in FP32.
A separate 60-step design objective gives matching material and waveform
derivatives. Complete checkpoint payload falls from 37,088 to 18,544 bytes
in this small geometry. This is a state-size and symmetry check, not a
large-domain throughput result. Direct CUDA derivative and transpose kernels
use compact CPML slab descriptors and one-dimensional profiles. A mixed-wall
case exercising both auxiliary families agrees with the CPU reference within
$7.45\times10^{-9}$ for traces, $2.98\times10^{-8}$ for material VJPs and
$4.77\times10^{-7}$ for waveform VJPs. These kernels are not fused across
curl terms, and their general absorption accuracy and execution speed remain
uncharacterized.

A restricted native adapter subsequently exposes mixed PMC and CPML through
ordinary Project, CLI and browser execution. It admits equal uniform spacing,
common PML depth and strength, and explicit cubic grading with unit kappa and
zero alpha. Unsupported profile values are rejected. The applied target-row
decay profile and fixed material collar are recorded in each result. Native
CPU fields and traces match the direct endpoint API, and an actual browser
workflow checks atomic profile selection and execution. This is an integration
result, not a general PML reflection or throughput measurement.

A second foundation partitions one periodic or Bloch problem into owned
$x$ slabs. Each rank stores only its local E/H, material and checkpoint banks.
One-row exchanges supply the magnetic-to-electric and electric-to-magnetic
curl dependencies. The transpose reverses these transfers and conjugates
only the global Bloch seam factor. Binomial replay retains a fixed local
checkpoint count, with an explicit maximum replay-work admission. Local
material derivatives are accumulated without a global field replication.

Two- and three-rank protocol tests use emulated transport to compare unequal
slabs, including a one-cell slab, with resident fields and material derivatives.
Independent halo inner products and local finite differences check the seams.
Three subsequent Linux CI cases execute actual two- and three-process Gloo
CPU groups, covering real and complex fields, scalar and diagonal material,
local state/material derivatives and independent seam checks. Gloo
initialization still fails on the current Windows runtime and a second CUDA
device is unavailable. These checks do not establish NCCL multi-GPU
execution, communication overlap or scaling. Sources, monitor
histories, CPML, mirrors and ADE are outside this distributed initial-value API.

\subsection{Matched cross-framework correctness}

A first comparison with FDTDX \citep{fdtdx-source} uses the same Linux RTX 3060
environment, a $16^3$ periodic dielectric grid, 100 nm spacing and 64 FP32
steps. Both solvers receive identical sampled permittivity and electric
source kicks and return two raw electric histories. The source cell remains
vacuum. Its reference pulse and detector locations are fixed, while a scalar
parameter perturbs the interior slab permittivity. Each implementation
requests four device checkpoints. Coordinate construction uses FP64 in
both setups to preserve an identical timestep, with FP32 dynamic state.

The two histories agree exactly for this fixture. Both objectives equal
$1.640023838263\times10^{-4}$ and both material derivatives equal
$-7.226401066873\times10^{-5}$. An independent homogeneous Fourier recurrence
has maximum absolute history error $4.552\times10^{-8}$. Three centered
finite-difference steps provide separate derivative checks. The record
\code{docs/validation/fdtdx_periodic_correctness.json} fixes software
revisions, artifact hashes, numerical conventions and setup corrections.
This finite periodic calculation does not establish open-boundary physical
accuracy, complete feature parity or comparative throughput and memory use.

A separate $64^3$, 512-step fixture compares the complete sampled
permittivity gradient, with the source cell still fixed. Native and FDTDX
checkpointed histories agree exactly, and the gradient relative $L_2$
difference is $1.06\times10^{-6}$. Scalar and seeded directional finite
differences provide independent checks. The FDTDX reversible path is also
admissible for this lossless periodic problem. With zero interior reversible
checkpoints and an empty recorder, its histories agree exactly and its
gradient differs from the native result by $1.97\times10^{-6}$ in relative
$L_2$ norm. Actual recorder array storage is zero for this fixture.
Reversible reconstruction and four-checkpoint replay are distinct algorithms
with different memory and recomputation costs. These correctness records
do not imply that the checkpointed FDTDX path is its fastest applicable
method, or establish an overall performance advantage.

\subsection{Opt-in lossless periodic reconstruction}

A separate \code{ReversibleSimulation} implementation now reconstructs
FP32 scalar-dielectric periodic fields from one owned terminal E/H pair.
It supports fixed impressed electric point increments and point E/H
observations. Absorbing, dispersive and tensor states are excluded from this
API. Reversible differentiation is an established approach, including in
FDTDX \citep{fdtdx-source}, and is not claimed here as a new algorithm.

For the stored native state, the inverse first recovers H using the new E,
then subtracts the electric source increment and recovers the old E.
The local transpose uses this reconstructed old H for the material VJP.
An ordinary negative-Courant forward step would have the wrong update order.
Each backward performs exactly one inverse and one transpose per timestep,
with no checkpoint replay. The immutable terminal pair is copied into live
working fields on every retained backward. Concurrent backwards on the
same result are rejected.

Field storage is $O(N)$, while source and point histories remain
$O(T(K+M))$ for $K$ prepared source terms and $M$ observation terms.
Admission includes terminal storage, live and adjoint fields, coefficients,
gradient, histories, observer metadata, source preparation and bounded
reduction scratch. Dynamic fields remain FP32. Diagnostic reductions use
FP64 chunks of at most 65,536 scalars without allocating full FP64 fields.
Absolute reconstruction residuals and their ratios to sampled forward
field scales are reported. An explicit drift threshold rejects failed
reconstruction before returning a gradient. This is a diagnostic, not a
theorem bounding objective-gradient error.

Native CUDA integration cases at $12^3$ cells and 96 steps and at $64^3$
cells and 512 steps have bitwise-equal histories to checkpointed execution.
The full material-gradient relative $L_2$ errors are
$4.09\times10^{-7}$ and $4.91\times10^{-7}$, respectively.
Distinct noncontiguous backward seeds also pass, and the systems, grids,
original fields and terminal pairs are released after their graphs.
These restricted checks do not establish arbitrary-duration accuracy,
beyond-VRAM capacity or a competitive throughput ranking.

\subsection{Recorded interfaces with a fixed absorbing exterior}

The separate \code{ReversibleCPMLSimulation} API extends interior
reconstruction to uniform real FP32 scalar nondispersive grids with periodic
$x/y$ boundaries and CPML on both $z$ faces. Actual staggered CPML target
rows determine an inclusive reconstruction interval $[a,b]$, separated from
the absorbing rows by a fixed collar. The caller supplies both a design
permittivity map and an explicit fixed exterior map. The effective material
is a copy of the exterior map with only $[a,b]$ replaced by the design map.
Its differentiable slice assignment therefore gives exactly zero design
cotangents outside that interval. It does not expose an unrestricted
exterior material VJP. Fixed impressed electric point increments lie inside
the reconstruction interval, while point E/H observations may also sample
the fixed non-PML collar.

Each forward timestep records four tangential planes between the electric
and magnetic updates. These are the new Ex/Ey at $z=b+1$ and the old Hx/Hy
at $z=a-1$. Reverse reconstruction restores these halos and updates only
interior H and E in inverse order. The full field and CPML auxiliary
transpose still propagates through the original domain, including the
absorbing exterior. No primal CPML auxiliary state is inverted, and the
interior material VJP reads only reconstructed lossless stencils. Recording
interfaces for reversible differentiation is established practice,
including in FDTDX \citep{fdtdx-source}, rather than a new algorithm claimed
here.

For $A=N_xN_y$ transverse cells, the four-plane FP32 archive requires
$16TA$ bytes and the owned interior terminal E/H pair requires
$24A(b-a+1)$ bytes. Total state storage is $O(N+TA)$, in addition to source
and point histories. The public API supports device or CPU trace storage
with synchronous transfers. These routes do not establish asynchronous
copy overlap or SSD-backed recording. Material assembly, live and adjoint
fields, auxiliary buffers, traces, terminal storage and reduction scratch
are included in the admission plan. Reconstruction residuals remain
reported drift diagnostics, not general gradient-error bounds.

Eleven public CPU tests pass, including absorbing trajectories through
2048 timesteps. Two public CUDA cases use a $6\times7\times20$ grid and
96 steps with two coincident electric sources, duplicate observations and
E/H monitors, including an electric observation in the fixed collar. Histories are bitwise equal to
checkpointed execution. The full admitted material-gradient relative
$L_2$ error is $5.34\times10^{-7}$ and a distinct retained backward seed
gives $3.64\times10^{-7}$. The initial reconstruction relative $L_2$
residual is $8.67\times10^{-7}$. These checks validate the restricted
public reconstruction and derivative contract. Test execution durations
are not throughput benchmarks, and physical reflection convergence,
beyond-VRAM transport and broader material or boundary scopes remain
separate validation tasks.

\section{Limitations and development priorities}

The native scope must be assessed by tested physical capabilities, supported parameter ranges and convergence evidence. Counting configuration properties cannot establish a product-completion percentage. In particular, a shared UI and Python schema does not establish that every requested observable or source type is physically implemented.

Near-term numerical priorities are physical output and shape-gradient convergence, independent validation of complete inverse-design runs, PMC and magnetic symmetry boundaries, eigenmode ports and mode expansion, and near-to-far objectives. Existing discrete material adjoints and regularized analytic shape derivatives do not imply differentiability of every scene property. General source parameters, additional material tensors and nonlinear models require their own derivatives and physical validation. Workflow priorities include concurrent adjoint batches, complete results inspection and reliable restart across supported execution modes.

The current browser uses an original identity, artwork and source code. Its workflow is organized around objects, regions, sources and monitors, with a separate periodic-density inverse-design editor. The hierarchical runtime provides lossless host and file-backed state banks, space-time slabs and asynchronous staging. Capacity demonstrations must be distinguished from long physical trajectories and competitive throughput. The analytic-geometry streaming API avoids dense material inputs and material VJPs through tile production and direct parameter reduction. Other dense material paths can still limit host capacity. Predictive scheduling, concurrent adjoint execution, complete distributed source/monitor workflows and actual multi-GPU validation remain development targets. Comparisons against additional libraries require common accuracy targets and a compatible measured GPU environment before any performance-leadership claim.

\section{Conclusions}

TorchFDTD provides Python and graphical workflows for a defined subset of time-domain photonics simulations. Its implementation exposes the conventions needed to interpret staggered fields, dispersive state, nonuniform mesh metrics and normalized flux. Ensemble execution supports repeated forward simulation. A separate PyTorch adjoint path connects supported material and shape parameters to inverse-design objectives using bounded replay and hierarchical state storage. The software and manuscript distinguish implemented capability, tested accuracy and outstanding work. Broader replacement claims, general performance guarantees and public distribution readiness remain unestablished.
